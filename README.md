# Gari Sim: Coleta Urbana 3D

Um jogo educativo e acessível sobre coleta seletiva e limpeza urbana. Dirija o caminhão, recolha os resíduos corretamente e descarregue as sacas no aterro antes que o tempo ou o combustível acabem.

## Jogar

Acesse a versão publicada:

**[Jogar Gari Sim](https://pedroallas.github.io/Gari-Sim/)**

> O jogo é executado diretamente no navegador e não exige instalação.

## Como jogar

1. Escolha a dificuldade: **Fácil**, **Normal** ou **Difícil**.
2. Dirija pelas ruas seguindo o radar e a seta amarela.
3. Recolha os quatro tipos de resíduos: papel, plástico, vidro e orgânico.
4. Descarregue as sacas no aterro para concluir a fase.
5. Evite os carros: colisões reduzem pontos e tempo.
6. Abasteça o caminhão no posto quando necessário.

### Controles

- **Teclado:** use as setas ou `WASD` para dirigir.
- **Espaço:** coletar, descarregar ou interagir.
- **Celular e tablet:** use os controles de toque na tela.
- **P:** pausar o jogo.

## Recursos

- Ambiente 3D com caminhão, ruas, trânsito e mapa de radar.
- Fases com pontuação, tempo, combustível e progresso.
- Coleta seletiva com quatro categorias de resíduos.
- Oficina e sistema de moedas para desbloquear melhorias.
- Configurações de volume, música e qualidade gráfica.
- Símbolos nas lixeiras para facilitar a identificação por pessoas daltônicas.
- Modo calmo, com menos tremores e luzes piscando.
- Qualidade gráfica automática para melhorar o desempenho em diferentes dispositivos.

## Tecnologia

O projeto é uma aplicação web independente, construída com:

- HTML, CSS e JavaScript;
- [Three.js](https://threejs.org/) para a renderização 3D;
- [Tailwind CSS](https://tailwindcss.com/) via CDN;
- GitHub Pages para publicação.

## Desenvolvimento local

Clone o repositório e abra `index.html` em um navegador. Para evitar restrições do navegador relacionadas a arquivos locais, você também pode iniciar um servidor simples:

```bash
python3 -m http.server 8000
```

Depois, acesse <http://localhost:8000>.

## Objetivo educacional

O Gari Sim busca transformar conceitos de coleta seletiva, segurança no trânsito e cuidado com os espaços urbanos em uma experiência interativa e acessível.
